# Exercise 00: Environment readiness and setup

## Exercise Learning Objectives
- Prepare the Azure environment for Microsoft Sentinel onboarding.
- Deploy the foundational resources required for the lab environment.
- Configure data collection and readiness settings needed for subsequent exercises.
- Enable Microsoft Defender for Cloud integration with Defender for Endpoint (MDE).

## Licensing and environment
- An active Azure subscription.
- Access to the Azure portal with permissions to deploy compute, networking, and security resources.
- Microsoft Defender for Cloud enabled in the subscription.
- Ability to deploy an Azure virtual machine and required monitoring components.

## Roles and permissions
- Lab environment: Owner or Contributor on the subscription to allow deployment of all required components.
- Real-world deployments: Contributor (or higher) on the resource group to deploy infrastructure.
- Permissions to enable Defender for Cloud plans and MDE integration.

## Estimated time
**20–30 minutes**
